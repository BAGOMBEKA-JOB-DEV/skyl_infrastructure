Secrets are synced by External Secrets. If pods are in CrashLoopBackOff, check
this first — the gateway treats "no provider key" as fatal, so an unsynced
secret looks like a broken image:

  kubectl -n {{ .Release.Namespace }} get externalsecret {{ include "skyl-gateway.fullname" . }}
  kubectl -n {{ .Release.Namespace }} describe externalsecret {{ include "skyl-gateway.fullname" . }}

  curl -H "Authorization: Bearer $SKYL_AUTH_TOKEN" localhost:8080/v1/providers

Two things worth knowing before you page someone:

  * /healthz stays 200 while the pod is draining, on purpose. Use /readyz to
    ask whether traffic should go there.

  * A rollout can take ~32s per pod. That is the documented drain, not a hang.
